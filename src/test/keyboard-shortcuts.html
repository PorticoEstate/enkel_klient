Keyboard Shortcuts for Language Switching

This application supports keyboard shortcuts for quickly switching between languages. The following shortcuts are available throughout the application:

Shortcut Action Platform
Alt + N Switch to Norwegian language Windows, Linux, macOS
Alt + E Switch to English language Windows, Linux, macOS

Note: These keyboard shortcuts are designed to work across all major browsers and operating systems. On macOS, the Alt key is equivalent to the Option key.

Accessibility Features

As part of our commitment to accessibility, we've implemented the following features:

  • Screen readers will announce language changes automatically
  • The language switcher is navigable via keyboard
  • A skip link allows you to bypass the navigation and go directly to the main content
  • All content is properly marked with language attributes for proper screen reader pronunciation
  • Enhanced keyboard focus visibility for all interactive elements

Keyboard Navigation Tips

  • Use Tab key to navigate through interactive elements
  • Press Enter or Space to activate buttons and links
  • Use the "Skip to content" link (press Tab once when page loads) to bypass navigation

If you experience any issues with keyboard navigation or language switching, please contact the system administrator.

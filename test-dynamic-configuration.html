Configuration Priority Order

1. Data Attributes - Highest priority, set directly on form element
2. JavaScript Files - Dynamic configuration from dedicated JS files
3. Twig Templates - Configuration from backend via window.formConfigs
4. Hardcoded Presets - Fallback configuration (deprecated)

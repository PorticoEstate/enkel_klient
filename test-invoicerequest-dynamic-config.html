Invoice Request Form - Dynamic Configuration Test

This form demonstrates dynamic configuration loading from multiple sources: data attributes, JavaScript config files, and Twig template configurations.

Configuration Sources (Priority Order)

  1. Data Attributes: Configured directly on the form element
  2. JavaScript Config File: /src/js/config/invoicerequest-config.js
  3. Twig Template Config: window.formConfigs from backend
  4. Hardcoded Presets: Fallback configuration in FormExtensionLoader

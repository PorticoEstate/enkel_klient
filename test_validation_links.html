Test Validation Error Links

This page tests that validation error summary links correctly focus on both regular form fields and Quill editor fields.

Test Form

Manual Testing Instructions

  1. Click "Test Validation" to trigger validation errors on empty required fields
  2. Check that an error summary appears at the top of the form
  3. Click each link in the error summary and verify:
    • Regular input fields (Name, Email) receive focus properly
    • Regular textarea (Description) receives focus properly
    • Quill editor fields (Details, Message) focus the editor content area
  4. Use "Clear Errors" to reset and test again
  5. Try entering some content in fields and re-testing to see partial validation

Focus Testing

When clicking error summary links:

  • Regular fields: Should focus the input/textarea element
  • Quill editors: Should focus the editor content (.ql-editor) and show a visible focus indicator
